# 诊断、数据与隐私

## 报告入口

“问题排查 → 导出问题简报”快速保存画面/声音/功能适配的关键状态。“完整诊断与按键采集”约3分钟，按引导操作；“只采集完整报告”约2分钟，跳过自动连接，仍包含42秒按键采集和60秒功能观察；并非完全没有观察窗口。实际耗时随车机/ROOT授权而变。报告留在车机共享存储的DiPlay目录，不自动上传。

完整诊断涵盖版本与环境、USB/连接阶段、ROOT与IPv6、解码器/音频队列与播放头、UI/触摸调度、GPS/MIC能力、原厂服务与方向盘输入等。权限失败/超时/缺素材会写入报告；没有输出不是“正常”的证明。

采集过程中可使用“收起后操作”，完成真实地图/音乐/方向盘/Siri场景后回到进度。按键观察窗口保留42秒；请按页面提示短按，不在行驶中操作。私有长ROOT诊断与正常连接ROOT分离，但采集仍消耗硬件资源。

## 建议一次采集

1. 原设置冷连接，正常音乐3分钟，地图/列表各操作20秒，记下卡顿时刻。
2. 测试暂停继续、上一/下一曲、导航提示与Siri后音乐恢复。
3. 拔线等断开，不重启App重连两轮。
4. 有问题先导出简报；需要时再运行一次完整诊断，按提示补按键/声音/GPS/MIC观察。
5. 可附约10秒手指和画面同镜视频，先遮住家庭地址、路线、通知、车牌和人脸。

## 可能包含的敏感信息

完整系统诊断可能包含设备/手机标识、序列号、IP/MAC、蓝牙/网络信息、应用清单、系统日志及定位线索。即使某个学习模块只存计数，**也不能推导整个完整报告没有隐私**。配对资料、签名密钥、认证证书/私钥、密码和Token不可贴到公开Issue。

公开反馈前人工检查并删减个人值；保留字段名、相对时间、状态码和必要上下文，使用明确的占位词。不要把整个桌面/工程/build目录打包上传。报告原件自行私下保存，公开仓库不追踪真实报告。请勿把未脱敏日志提交到本仓库。

## 自学习保存与权限

性能规则保存有界统计/档位，不上传云端；麦克风采样不保存原始录音；GPS质量观察不保存轨迹。普通运行仍会使用定位/音频API及本地配对/身份存储，设备应由使用者妥善保管。撤销/重置学习和卸载应用是不同操作；卸载可能丢配对/设置，不能把卸载当默认排查步骤。

本仓库只附检查工具，不承诺自动识别任意格式、历史归档或所有隐私。未来每次提交/发包都要重新核对。
