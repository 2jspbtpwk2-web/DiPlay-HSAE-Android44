# 完整使用说明

## 1. 软件与安装

DiPlay 安装在车机上，iPhone 继续使用自身 CarPlay 功能。本适配主线是有线 USB，不是给手机安装的 App，也不要求用户向第三方认证服务器上传手机资料。

本仓库只发布脱敏源码，不提供包含私有运行身份的现成 APK。自行构建的默认无身份包可检查界面/兼容性，不能直接完成独立附件认证；完整运行依赖见 [Legacy构建说明](../adaptation/receiver/BUILD.md)。不要把原私有测试 APK 上传到公开 Release。

使用合法可用的完整本地包时：核对包名和签名后覆盖安装可保留配对/设置。不同签名不能直接覆盖原包，不能为了方便把原签名私钥发给别人。先备份个人需要的数据，再自行决定签名变化时的迁移方式。

## 2. 日常连接

1. 停稳车辆，解锁 iPhone；用数据线连接车机数据 USB 口。
2. 允许系统实际出现的 USB/ROOT 提示，进入软件点击“连接 CarPlay”。手机出现的授权由用户确认。
3. 等待连接阶段推进。保留原有等待/重试；首次配对、USB 重枚举和旧固件操作可能较慢。
4. 连接后触摸地图/列表；通过菜单返回主页。“返回 CarPlay”回当前投屏，“Siri”请求手机语音，“返回车机”回车机桌面。
5. 拔线后等软件显示断开，再重新插入。不要在仍处理上次资源时连续反复点击连接。

手机是否每次弹窗由 iOS 配对/授权状态决定；没有新弹窗本身不能证明连接成功或失败。优先看实际阶段、RECORD、首帧和真实画面。不能用手机已充电代替数据链路确认。

## 4. 设置

### 画面

自动适配/流畅优先/清晰优先/自定义按使用需要选择。自动模式依据应用实际可用区域保持比例；原厂空调/系统预留区不属于本App，不能靠填满硬件分辨率覆盖。帧率可选15/24/30，选择30不等于实际显示恒定30。自定义宽640～1920、高360～1920，比例3～10；手动分辨率还需选“自定义”才采用。

### 声音

先调车机媒体音量，App内音量是自身播放比例。音乐启动缓冲默认300ms，可选500/1000ms；更大可能缓解短时供给不足，同时增加等待，不能当作低延迟档位。音质参数和播放速度不随该缓冲选择降低或加速。建议保持音频焦点管理；导航压低音乐是可选音量行为。

### 麦克风与 GPS

分别允许使用车机麦克风和车机定位；还需系统能力及下一次连接实际协商。关闭物理麦克风采集时，本实现保留所需输入端点并使用合成静音，不能把端点存在误认为正在录音。GPS开关不会替用户强开系统定位；定位更新/发送计数不证明手机已经采用。

### 方向盘与连接

方向盘切歌转发默认需要用户确认原厂功能无效后显式启用；语音键、开机准备等按页面设置。重试受软件运行、USB设备、权限及每轮退避条件控制；没有承诺固定总尝试次数，也不据此更改原厂播放器行为。

### 外观

原测试版有车身图片选择。公开源码已排除未经确认许可的车图和车标，因此可能保留空白/预留区域；新图标是原创占位图，不代表现代或Apple官方标识。

## 5. 功能适配 / 自学习

### 自动优化画面

开启后拔线重连，返回真实 CarPlay 持续滑动地图/列表约40秒，再回页面查看。工具页面、后台、诊断、语音或静态窗口不用于判断正常触摸下的画面负载。达到原规则才对**下次连接**建议降低一档分辨率；当前会话不改、不自动断线。可以固定、回退或重置。它不提高硬件能力、不学习任意模型，也不保证最佳画质/最低延迟。

### 方向盘切歌

先播放 CarPlay 音乐，试原厂上一曲/下一曲。原厂已有效则无需启用转发。无效再进向导：下一曲短按两次、上一曲短按两次；保存确认后重连。识别可在不连手机时进行，实际转发需要当前CarPlay媒体条件。仅适配已有证据的HSAE短按，不猜任意CAN协议。一次按键切两首则关闭转发；原厂播放器仍可能响应。

### 麦克风

先开启车机麦克风并断开手机，选择方案A/方案B，安静和说话各约3秒。保存“下次连接试用”候选，重连后实测Siri/通话，确认物理MIC确实有效再记住结果。电平有变化不代表手机采用或语音识别成功。采样不保存原始录音，候选失败可恢复默认；校准不能和活动语音同时抢录音资源。

### 本地声音与 GPS

声音工具在断开手机后播放短提示，只证明本地播放API，不等于CarPlay路由正常。GPS观察在开阔处停车最多30秒，保留质量统计；实际导航采用还需手机确认。

## 6. 常见问题

| 情况 | 先检查 |
| --- | --- |
| 只有充电/停在连接阶段 | 数据线、数据USB口、USB/ROOT授权，记录卡住阶段并导出报告 |
| 手机出声、车机无声 | 是否真的开始CarPlay媒体、原厂音源/焦点、流协商和AudioTrack统计；工具不会自动切换OEM音源 |
| 卡碟/音乐延迟 | 先保持300ms，连续播3分钟并记录发生时刻；不要同时变更多个参数 |
| 地图卡、设置流畅 | 投屏解密/排队/解码/输出与触摸往返链路需分别看；设置流畅不能证明投屏无瓶颈 |
| 按键只切原厂音乐 | 播放CarPlay实测后再使用识别向导；不要直接假设必须转发 |
| GPS/MIC有计数却无效果 | 计数不等于iPhone采用，按功能向导做真实确认 |

反馈步骤见 DIAGNOSTICS_AND_PRIVACY.md。优先一次正常音乐/地图复现，再做必要采集；重型诊断会增加CPU/IO负载，不能把采集期间的性能当普通使用性能。
